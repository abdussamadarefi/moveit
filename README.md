## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/moveit.git
```

2. Install dependencies:
```bash
npm install
```

3. Start development server:
```bash
npm start
```

4. Watch SCSS changes:
```bash
npm run sass
```

5. Build for production:
```bash
npm run build
```
